# Migration from the prototype

How each feature of `battery_platform_demo.html` maps to the React app. Nothing was dropped silently. The two small changes in behaviour are listed at the end.

## Workspace

| Prototype | React |
| --- | --- |
| Four stat cards linking to other screens | `pages/Workspace/StatCard.tsx`. The cards are now real links. "Tested pairs" scrolls to the Explore list instead of opening Charts. |
| "Materials at a glance" mini scatter | `ScatterChart` with `compact`. Its axes are now computed from the data instead of fixed at 300–500 and 40–100%. |
| Paper status donut | `components/charts/DonutChart.tsx` |
| Explore tabs with arrow-key navigation | `components/common/Tabs.tsx`. Home and End also work now. |
| Quick questions, filters, "More options" with an "N on" badge, Clear | `FindPairsPanel.tsx`, with state in `ViewStateContext` |
| Pair list with Compare picks (max 3, oldest dropped) | `components/tables/PairList.tsx` and `domain/pairs.ts` `togglePick` |
| Compare table, chemical formula subscripts | `CompareTable.tsx`, `Formula` |
| Untested-pairs grid, click goes to Find pairs | `UntestedGrid.tsx` and `domain/pairs.ts` `buildPairGrid` |

## Behaviour changes

1. **The prototype's Amplifi adapter is gone.** It posted `{ chat_app_id, message }` straight to Amplifi and guessed the answer field. The browser now talks only to a proxy with a defined contract (see INTEGRATION.md), so no credentials or unverified Amplifi details live in frontend code.
2. **Feedback wording.** The thumbs-up toast no longer says the feedback "helps improve the answers", because nothing is sent yet. It now says the rating is noted for this session.

Two decorative animations were not carried over: the slide-out when a review item leaves the queue, and the shadow on the top bar when the page scrolls.
